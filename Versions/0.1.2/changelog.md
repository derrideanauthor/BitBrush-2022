13 July Updates Log
===================
##Version 0.1.2

----------------------------------------------------------------------

Features Added:

	* Layer isolate mode (a button added to the layer panel's title bar) allows you to only see the layer you are currently working on.
	
Fixes:

	* Eyedropper tool single click now works
	* Filling with the floodfill tool using the same colour as the target colour no longer crashes the app.

Upgrades:

	* Animation preview now greys out what is not seen on the canvas. Ugly red square removed. 
	* Bitbrush (.bitbr) files are now smaller by a factor of 3.5 using a custom data algorithm.
