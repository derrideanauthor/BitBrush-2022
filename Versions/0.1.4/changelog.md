27 July 2018 Updates Log
========================
##Version 0.1.4

----------------------------------------------------------------------

File Saving:

	* Custom color swatches now saves together with the project file.

Navigation upgrades:

	* Panning around is now possible by selecting the pan tool (Navigation tools). Panning boundary is now set to 1/2 the pasteboard.
	* Holding the spacebar now switches to the panning tool in order to quickly navigate while using any tool.
	* The artboard is no longer locked to the center.
	* A "Center artboard" button has been added to the navigation drawer.

UI Fixes:

	* The project name field will now revert to "Untitled" if left blank.
	* The Onionskin gizmo to the right on the timeline now functions properly.
	* Inputting a hex color value now updates the shades/tints and harmonies widgets.
	* The heading on the timeline  did not properly update when frame was removed. The issue has been resolved.

UI Upgrades:

	* Shades and Tints now display the original reference color to the left.
	* New favicon (browser tab icon) design (*trial).
	* Added an extra visual effect to highlight frames being animated (*trial).
	
New Additions:

	* A crude export menu has been added. Press the "export" button in the timeline to open.
	* PNG exporting is now available (current frame only).
	* Additional (hover over) tooltips added to the top toolbar.
	* Additional user feedback dialogues added to the selection tool functions.
	* Shortcuts for the selection tool functions (copy, paste, etc.) has been added.
