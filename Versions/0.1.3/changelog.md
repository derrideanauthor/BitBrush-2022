20 July Updates Log
===================
##Version 0.1.3

----------------------------------------------------------------------

Pen and Touch:

	* Added a cursor change. Pen input will show a simple crosshair as cursor while normal mouse movement will have the cursor assigned by the tool.
	* Color picker and other gizmos now support use with pen/touch.

Upgrades:

	* Saved files now compiles using a compression algorithm to reduce file size dramatically.

Fixes:

	* The project name is now included in a save file. Saving custom swatches will be included in the next update.
	* Pen/touch interaction with static buttons now work
	
Additions:

	* A History panel can now be accessed by pressing Ctrl/CMD+SHIFT+H
